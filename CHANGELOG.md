# Изменения

## 0.3.1

- При устаревшей службе интерфейс больше не показывает сырые ошибки протокола («unknown variant») за цепочки, списки и переключатель остального трафика: вместо этого — человеческое «Служба устарела, обновите её на вкладке «Главная»».
- Исправлен путь кэша mihomo: каталог запуска больше не передаётся с префиксом `\\?\`, из-за которого mihomo не мог открыть `run/cache.db` (предупреждение в логе на реальной установке).

## 0.3.0

- Цепочки: именованные цепочки до трёх звеньев (сервер/страна/VPN) как цель маршрута и как путь по умолчанию для всего VPN (dialer-proxy, уровни — fallback-группы; при несборке — обычный VPN, никогда напрямую).
- Списки-папки: именованные наборы сайтов/программ с подключением к маршрутам по ссылке; эффективные записи (свои + из папок) двигают активность маршрутов, файлы правил и горячую перезагрузку; поиск по спискам и маршрутам.
- Своё направление у списка: список с целью сам становится единицей маршрутизации после маршрутов («ИИ» — через США, «Геоблок» — через самый быстрый VPN).
- Исправлен дедлок движка на первом route_add: connected() вызывался под уже взятым мьютексом состояния и вешал однотредовый рантайм.
- WireGuard/AmneziaWG: фоновая перепроверка — не чаще раза в сутки; WARP-варианты при сканировании проверяются, только пока нет ни одного рабочего; неизтерактивный замер скорости пропускает WG.
- Диалог цели маршрута разрезан на три отдельные модалки (устранено обрезание нижней сноски).

## 0.2.0

- Портативная установка: программа работает из папки, куда её распаковали; служба
  запускается оттуда же. Папка защищается (владелец — администраторы, пользователям
  только чтение и запуск), неудачные места (профиль, съёмные/сетевые диски, FAT,
  запуск из zip) — предупреждение или запрет. Автоматический переход с 0.1
  (Program Files / ProgramData, ярлык «Пуск», запись в «Приложениях»).
- Обновление: запуск новой копии → «Обновить» → файлы копируются в папку программы,
  окно перезапускается оттуда (`--replace`).
- Быстрое переключение при сбое сервера (≈10–15 с) с уведомлением.
- Замер скорости: автоматически для лучших серверов (несколько адресов на случай
  блокировки), вручную — «Замерить» в карточке сервера. Стабильность по истории проверок.
- Сортировка (лучшие / пинг / скорость / стабильность), фильтр по странам, избранное.
- Карточка сервера (протокол, адрес, пинг, скорость, стабильность, сервисы, дата проверки).
- DNS через VPN (DoH через туннель), блокировка Teredo при включённом VPN.
- Исправлено: кодировка сообщений в журнале; окно частично не перерисовывалось после
  сворачивания/разблокировки (полная перерисовка по запросу системы и при фокусе).
- Движок корректно останавливается по SIGTERM (режим разработки на Linux).

## 0.1.0

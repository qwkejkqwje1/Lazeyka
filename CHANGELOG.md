# Изменения

## 0.7.0

- Поиск серверов: исправлена главная причина «находит мало» — при заполненной базе (1500) непроверенные серверы из списков вытеснялись и на 21 день попадали на «кладбище», так ни разу и не проверившись. Теперь кандидаты держатся в памяти, в базу попадают только проверенные; лишние рабочие при обрезке откладываются на 2 дня, непроверенные не хоронятся вовсе. Дата первого появления сервера помнится 14 дней.
- Разведчик учится: подсети /24 и SNI рабочих и мёртвых серверов за последние 2 дня задают порядок проверки; лимит кандидатов от источника подстраивается под его долю успеха; все «не ответившие» в каждом батче проверяются ещё раз через запасной тестовый адрес с удвоенным таймаутом; статистика источников со временем «стареет».
- +14 источников серверов (Reality/VLESS/Trojan для России, белые списки CIDR и др.), у всех проверены адреса и зеркала jsDelivr. Списки источников скачиваются через VPN, если туннель уже работает (иначе — напрямую).
- Маршруты: под полем «Сайт или программа: куда отправить?» — кнопки «Напрямую», «Через VPN», «Страна, сервер…», «Блокировать». Запись добавляется в подходящий маршрут (или создаётся новый) и убирается из других. После любой правки маршруты упорядочиваются сами (частные правила выше общих).
- Списки со своим направлением стали маршрутами с подключённым списком; у списка видно, в каких маршрутах он используется.
- Цепочки: новое звено «WARP» (например, «VPN → WARP», если WARP напрямую не работает в вашей сети). В настройках и выборе направления показывается состояние WARP.
- Всплывающие уведомления больше не перехватывают нажатия (раньше кнопки под ними «переставали нажиматься»); уведомление — вверху окна.
- Ссылки: `security=false/0/auto` — без TLS, транспорт `none` — TCP, отбрасывается мусор после `#` в типе транспорта.

## 0.6.1

- Свой WireGuard / AmneziaWG как входное звено: вставьте конфиг (`.conf`, Clash YAML с `type: wireguard`, `vpn://` Amnezia) в «Мои серверы» — пока он проходит проверку, через него (и только через него) проверяются остальные серверы. Один ключ — один туннель: при активном подключении лаборатория не открывает тот же WG повторно, а в основном конфиге звено живёт одной копией.
- Приоритет звена: свой/избранный сервер → Reality → остальные по оценке. Бесплатные WireGuard-профили и WARP звеном не бывают.
- Серверы, оживающие только через звено, — запасной уровень: в авто-выборе они всегда ниже серверов, работающих напрямую.
- Чистка базы жёстче: сервер мёртв, если ни напрямую, ни через звено не работал 3 дня (ни разу — 2 дня); закрытые отсюда серверы сначала получают попытку через звено (до недели). В базе остаётся не более 1500 бесплатных серверов: сначала уходят неработающие. Списки источников скачиваются заново при каждом поиске.
- Пакет обновления распаковывается в `<папка Лазейки>\update` рядом с `lazeyka.exe` (раньше — `%ProgramData%\Lazeyka-update`); после обновления и при удалении Лазейки папка чистится.
- WARP: если ни один вариант не прошёл проверку, повторная проверка — раз в 6 часов (кнопка поиска проверяет сразу), в журнале и уведомлении — «WARP недоступен в вашей сети».

## 0.6.0

- Проверка через входное звено: серверы, которые не отвечают напрямую (порт закрыт, нет ответа), проверяются ещё раз через рабочий сервер. Оживший сервер работает цепочкой «звено → сервер» (dialer-proxy), помечается в пуле и пересчитывается вместе с ним; пропал вход — сервер выключается сам. Отключается в «Настройки → Серверы».
- Чистка базы: серверы, мёртвые неделями (не работали 14 дней или ни разу за 7 дней при ≥3 неудачах), удаляются и попадают на «кладбище» на 21 день — источники не возвращают их обратно, поиск тратит время только на живых. Об удалении пишется в журнал.
- Стратегии для страны: «По порядку» (по умолчанию, стабильный выход), «Быстрейший» (url-test с допуском 50 мс) и «Баланс» (load-balance, один сайт — один сервер).
- Обновления: проверка новых версий программы и mihomo раз в 12 часов (можно выключить). mihomo скачивается, проверяется по SHA-256, запускается для проверки версии и подменяется с сохранением `.old`; программа скачивается и устанавливается кнопкой в «Настройки → Обновления».
- Главная: «Всего через VPN: ↓ … · ↑ …» — трафик за всё время (счётчики mihomo, без нагрузки; запись на диск раз в минуту).

## 0.5.0

- Маршрут страны: «Если в этой стране нет рабочих серверов» — самый быстрый (по умолчанию), WARP, напрямую или блок. Запасной вариант стоит в конце цепочки, поэтому при появлении серверов страны трафик возвращается к ним сам; по умолчанию трафик никогда не уходит напрямую.
- Кнопка «Упорядочить» в предупреждениях маршрутов: частные правила автоматически ставятся выше общих, остальной порядок сохраняется.
- Поиск серверов: новые источники (delta, openray, rooster, mhdi; aliilapro — по желанию), зеркало jsDelivr для списков с GitHub; свежие серверы проверяются первыми; серверы стран, нужных маршрутам, — в первую очередь.
- Быстрый отсев по TCP до полной проверки (пропускается, если сеть выглядит подозрительно, и для UDP-протоколов), а в журнале — причины отказов: сколько серверов отпало из-за таймаута, закрытого порта, TLS/Reality и т. д.

## 0.4.0

- Каталог наборов: готовые маршруты в один тап — Google Gemini, ИИ-сервисы, YouTube, соцсети, мессенджеры, стриминг, разработка, игры, российские сервисы, локальная сеть, обновления Windows, торренты. Выбираете набор и направление (рекомендация подсказана) — маршрут готов. Повторный выбор дополняет и перенаправляет уже созданный.
- «Куда пойдёт сайт или программа?»: вставьте адрес или имя .exe — Лазейка объяснит, какой маршрут решает, какое правило сработало и какие маршруты перекрыты.
- Проверка маршрутов: предупреждения о дублях, о правилах, которые никогда не сработают (общий домен выше частного), пустых маршрутах, удалённых списках и цепочках.
- Умная вставка: в поле сайта и по кнопке «Вставить из буфера» принимается что угодно — списки через пробел/запятую/строки, URL, `*.example.com`, строки hosts и Clash (`DOMAIN-SUFFIX,x.com`), `domain:`, `||x.com^`, пути к программам. Сайты и программы распознаются сами.
- Поиск рабочих серверов: вместо бана на 6/48 часов — нарастающая пауза 20 мин → 6 ч; при сбое сети или недоступном тестовом адресе серверы больше не штрафуются (повторная проверка через другой адрес с увеличенным таймаутом).
- Копирование и вставка в полях ввода работают при русской и украинской раскладке (Ctrl+С/V/X/A), а также Shift+Insert, Ctrl+Insert, Shift+Delete.

## 0.3.1

- При устаревшей службе интерфейс больше не показывает сырые ошибки протокола («unknown variant») за цепочки, списки и переключатель остального трафика: вместо этого — человеческое «Служба устарела, обновите её на вкладке «Главная»».

## 0.3.0

- Цепочки: именованные цепочки до трёх звеньев (сервер/страна/VPN) как цель маршрута и как путь по умолчанию для всего VPN (dialer-proxy, уровни — fallback-группы; при несборке — обычный VPN, никогда напрямую).
- Списки-папки: именованные наборы сайтов/программ с подключением к маршрутам по ссылке; эффективные записи (свои + из папок) двигают активность маршрутов, файлы правил и горячую перезагрузку; поиск по спискам и маршрутам.
- Своё направление у списка: список с целью сам становится единицей маршрутизации после маршрутов («ИИ» — через США, «Геоблок» — через самый быстрый VPN).
- Исправлен дедлок движка на первом route_add: connected() вызывался под уже взятым мьютексом состояния и вешал однотредовый рантайм.
- WireGuard/AmneziaWG: фоновая перепроверка — не чаще раза в сутки; WARP-варианты при сканировании проверяются, только пока нет ни одного рабочего; неизтерактивный замер скорости пропускает WG.
- Диалог цели маршрута разрезан на три отдельные модалки (устранено обрезание нижней сноски).

## 0.2.0

- Портативная установка: программа работает из папки, куда её распаковали; служба
  запускается оттуда же. Папка защищается (владелец — администраторы, пользователям
  только чтение и запуск), неудачные места (профиль, съёмные/сетевые диски, FAT,
  запуск из zip) — предупреждение или запрет. Автоматический переход с 0.1
  (Program Files / ProgramData, ярлык «Пуск», запись в «Приложениях»).
- Обновление: запуск новой копии → «Обновить» → файлы копируются в папку программы,
  окно перезапускается оттуда (`--replace`).
- Быстрое переключение при сбое сервера (≈10–15 с) с уведомлением.
- Замер скорости: автоматически для лучших серверов (несколько адресов на случай
  блокировки), вручную — «Замерить» в карточке сервера. Стабильность по истории проверок.
- Сортировка (лучшие / пинг / скорость / стабильность), фильтр по странам, избранное.
- Карточка сервера (протокол, адрес, пинг, скорость, стабильность, сервисы, дата проверки).
- DNS через VPN (DoH через туннель), блокировка Teredo при включённом VPN.
- Исправлено: кодировка сообщений в журнале; окно частично не перерисовывалось после
  сворачивания/разблокировки (полная перерисовка по запросу системы и при фокусе).
- Движок корректно останавливается по SIGTERM (режим разработки на Linux).

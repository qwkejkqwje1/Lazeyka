# Lazeyka — Архитектурная справка и журнал восстановления

## Текущее состояние (версия 0.8.0)

Репозиторий содержит полное рабочее дерево пакетов `lazeyka` (интерфейс Slint, системный трей и служба Windows) и `lazeyka-core` (движок, многоступенчатый сканер, маршрутизатор, генератор конфигураций `mihomo`, модуль бесплатных провайдеров и защищённого хранения учётных данных).

### Ключевые архитектурные инварианты 0.8.0

1. **Безопасность портативной службы Windows (`src/win.rs`):**
   - Служба `Lazeyka` работает от имени `LocalSystem` из портативной папки программы.
   - Установка службы разрешена только на томах с поддержкой постоянных ACL (`FILE_PERSISTENT_ACLS`, т.е. NTFS/ReFS).
   - Вызов `protect_home` при установке обязателен: при любой ошибке установки ACL выполняется откат (`unprotect_home`), а регистрация службы отменяется.
2. **Безопасность обновлений (`core/src/update.rs`, `core/src/engine/update_ops.rs`):**
   - Любой загруженный архив или бинарный файл проверяется по SHA-256 (через поле `digest` GitHub API либо 64-символьный SHA-256 из описания релиза).
   - Перед запуском `mihomo -v` или установщика обновления проверяется корректность заголовка PE (`MZ`, `PE\0\0`, машина `0x8664`).
   - Распаковка ZIP ограничена по числу файлов, суммарному объёму и защищена от `..` (Zip Slip) и дублирующихся имён.
3. **Защита от утечек и перехвата (`core/src/mihomo.rs`, `core/src/routes.rs`):**
   - Нешифрованный трафик на порт 80 (`PLAIN`) никогда не отправляется через публичные бесплатные узлы. По умолчанию при отсутствии собственного сервера и WARP используется `REJECT` (без скрытого обхода VPN через `DIRECT`), если пользователь явно не включил `http_allow_direct`.
4. **Идемпотентность маршрутов и Circuit Breaker (`core/src/engine.rs`, `core/src/engine/route_ops.rs`):**
   - Группы `R-<id>` работают в режиме `lazy: true` (`interval: 300`).
   - Узлы, переставшие отвечать в `R-<id>-s` (включая `R-__default-s`) или в основном пуле, изолируются через `trip_circuit` и вытесняются из активных групп.
   - Обновление пула бесплатных серверов перезагружает только `pool.yaml` через `reload_proxy_provider`, не вызывая лишних `reload_main()`.
5. **Строгий выбор страны (`core/src/scan.rs`):**
   - При непустом списке выбранных стран `scan::pool` возвращает только серверы с выходом в выбранных странах (плюс явно выбранный вручную сервер) без скрытой подмены на другие страны.
6. **Хранение учётных данных и секретов (`core/src/providers.rs`, `core/src/store.rs`):**
   - Ключи WARP и токены провайдеров защищаются на диске через Windows DPAPI (`CryptProtectData` с флагом `CRYPTPROTECT_LOCAL_MACHINE`) и аутентифицированное шифрование, а при экспорте для переноса шифруются паролем пользователя.
   - В журналах движка и `mihomo` приватные ключи, пароли, UUID и токены автоматически маскируются (`[СКРЫТО]`).

# Лазейка и Clash Verge Rev: сравнение

Дата: 5 ноября 2026 года. Факты о Clash Verge Rev — из его официального репозитория на GitHub, страницы релизов и документации (ссылки в конце). Факты о Лазейке — из текущего состояния проекта.

## Коротко о проектах

**Лазейка** — Windows-клиент на Rust с интерфейсом на Slint (без WebView) и ядром mihomo в виде отдельного процесса-сайдкара; движок работает как ядро с IPC-API, которым пользуется интерфейс. Главная идея — пользователю не нужен свой сервер и своя подписка: клиент сам находит бесплатные публичные источники, проверяет серверы параллельными тестами (задержка, страна выхода, доступность сервисов, UDP, скорость), ставит им оценки и держит готовый пул с автоматическим переключением при отказе. Поверх этого — маршруты: именованные наборы сайтов и программ, каждый со своей целью (напрямую, VPN, страна, конкретный сервер, WARP, блокировка или именованная цепочка до трёх звеньев). Принципы: простота для нетехнического пользователя, лёгкость, портативность (файлы рядом с exe), расчёт на обход блокировок в российских сетях. Проект молодой, предрелизный: версия 0.2.0 плюс неопубликованная разработка (маршруты, цепочки), сообщества пока нет.

**Clash Verge Rev** — продолжение (форк) закрытого в 2023 году проекта Clash Verge, развивается сообществом с ноября 2023 года. Это графическая оболочка вокруг того же ядра mihomo для Windows, macOS и Linux: пользователь приносит свою подписку (обычно платного провайдера или собственный сервер), а клиент управляет профилями-конфигами, системным прокси и TUN-режимом. Интерфейс — Tauri 2: бэкенд на Rust, фронтенд на React/TypeScript, отображается через системный WebView. Проект зрелый и массовый: на момент проверки у репозитория около 156 тысяч звёзд и более 11 тысяч форков, релизы выходят регулярно — последняя стабильная версия v2.5.10 от 3 ноября 2026 года (в v2.5.9 неделей раньше ядро mihomo обновили до v1.19.33). Серверов клиент не поставляет: это инструмент для чужих подписок, а не VPN-сервис.

## Сравнение

| Измерение | Лазейка | Clash Verge Rev |
|---|---|---|
| Платформы | Только Windows | Windows (x64, x86, ARM64; Windows 7 больше не поддерживается), macOS 11+ (Intel и Apple Silicon), Linux (x64, ARM64, ARMv7; пакеты deb и rpm) |
| Ядро | mihomo, отдельный процесс-сайдкар, управляется движком через API | Тоже mihomo (поставляется как verge-mihomo), есть переключение на Alpha-канал ядра; два режима запуска: привилегированная служба для TUN или непривилегированный сайдкар |
| Стек / UI | Rust + Slint, нативный интерфейс без WebView; движок отделён от интерфейса IPC-интерфейсом | Tauri 2: Rust-бэкенд + React/TypeScript, интерфейс рисует системный WebView (на Windows — WebView2) |
| Источник серверов | Встроенный каталог бесплатных публичных источников: «разведчик» сам скачивает подписки агрегаторов, тестирует серверы через отдельную лабораторную копию mihomo (задержка, страна выхода, сервисы, UDP, скорость), оценивает и собирает рабочий пул с failover. Своя подписка не нужна; свои серверы и подписки тоже можно добавить | Своих серверов нет вообще. Нужна готовая подписка провайдера или собственный сервер: профили импортируются по URL или локальным файлом в формате Clash/mihomo, обновляются по расписанию. Отдельного поиска бесплатных серверов нет |
| Маршрутизация и правила | Маршруты — именованные наборы «сайты + программы» с одной целью на набор; порядок сверху вниз, первое совпадение выигрывает; остальной трафик — через VPN или напрямую (на выбор). Списки маршрута правятся в интерфейсе, YAML не нужен | Полная модель mihomo: правила всех типов (домены, IP, GEOIP/GEOSITE, процессы и т.д.), провайдеры правил, группы select / url-test / fallback / load-balance; визуальные редакторы узлов и правил плюс прямой доступ к YAML. Режимы Rule / Global / Direct |
| Цепочки / multi-hop | Именованные цепочки до 3 звеньев (звено — сервер, страна или «авто»); строятся через dialer-proxy в генерируемом конфиге. Одна цепочка переиспользуется: как цель маршрута и как глобальный путь для всего VPN-трафика. Не собравшаяся цепочка уводит трафик в запасной VPN, а не напрямую | Тоже есть, двумя путями: режим «цепной прокси» в интерфейсе (с версии 2.4.5: на странице узлов узлы нажимаются по порядку — вход, промежуточные, выход; работает для ручной группы или глобально) и dialer-proxy / группы relay в конфиге, Merge и скриптах для цепочек по правилам. Ограничение в 3 звена не задано — сколько пропишете, столько и будет |
| Расширяемость конфигурации | Не предусмотрена: конфиг mihomo генерирует движок, руками его не правят | Сильная сторона: профили-расширения Merge (YAML-слияние) и Script (JavaScript-преобразование конфига), глобальные и на каждую подписку; шаблоны правил/узлов/групп; синтаксические подсказки в редакторе; бэкап и синхронизация через WebDAV |
| Простота для новичка | Рассчитана на «включил — работает»: серверы находятся и проверяются сами, решения принимает скоринг; от пользователя нужны только маршруты в терминах «сайты и программы» | Нужна своя подписка и понимание базовых понятий (профиль, группа, режим, системный прокси против TUN). Интерфейс богатый, разделов и настроек много; документация и гайды сообщества это частично компенсируют |
| Ресурсы и портативность | Заявленные принципы: малый расход ресурсов, файлы рядом с exe, ПК не засоряется. Установщик как продукт пока не оформлен (предрелиз) | Установочные пакеты примерно 50–100 МБ в зависимости от платформы; данные и конфиги лежат в системном каталоге приложения (на Windows — %APPDATA%), для TUN ставится системная служба |
| Зрелость и сообщество | Предрелиз: 0.2.0 и неопубликованные ветки разработки; пользователей и сообщества нет, поддержка — один разработчик | Зрелый проект с ноября 2023 года: ~5 тысяч коммитов, 75 релизов, регулярные обновления (2.5.5–2.5.10 за сентябрь–ноябрь 2026), большое сообщество, Telegram-канал, подробная документация |
| Лицензия | GPL-3.0 | GPL-3.0 |
| Модель угроз / защита от утечек | Защита от утечек — встроенная политика, а не настройка: пустая группа маршрута отвечает REJECT, маршрут при отказе своих серверов уходит в VPN и никогда молча напрямую, TUN в строгом режиме (strict-route). Слабое место модели — сами бесплатные серверы: они чужие, их владельцы видят трафик, поэтому скоринг меряет живость и характеристики, но не честность оператора | Клиент честно заявляет (политика приватности): телеметрии нет, данные не собираются, конфиги и логи только локально. Но защита от утечек определяется подпиской пользователя: какие правила, DNS и fallback заложил провайдер, так и будет; DIRECT — обычная политика в конфигах, fail-closed как политики клиента нет. Системный прокси снабжён «сторожем», который восстанавливает настройку, если её сбросили |

## Где сильнее Clash Verge Rev

- **Платформы и зрелость.** Три десктопные ОС против одной Windows; годы эксплуатации, десятки релизов, огромное сообщество и документация против предрелиза без пользователей.
- **Глубина конфигурации.** Всё, что умеет mihomo, доступно напрямую: любые правила и провайдеры, группы всех типов, Merge- и Script-расширения, ручная правка YAML. Лазейка сознательно генерирует конфиг сама и такой свободы не даёт.
- **Качество источника серверов.** Своя подписка платного провайдера или собственный сервер — предсказуемая скорость и понятный оператор. У Лазейки бесплатные публичные серверы нестабильны и недоверенны по построению.
- **Цепочки без потолка.** Режим цепного прокси в интерфейсе плюс dialer-proxy в конфиге позволяют цепочки любой длины и точечно по правилам; у Лазейки — максимум 3 звена (осознанное ограничение ради простоты).
- **Экосистема.** WebDAV-бэкапы, темы и CSS-инъекции, Alpha-канал ядра, совместимость с гигантским объёмом существующих Clash-конфигов и гайдов.

## Где сильнее Лазейка

- **Ноль на входе.** Не нужна ни подписка, ни сервер, ни понимание предмета: каталог бесплатных источников, автотест и скоринг дают рабочий VPN из коробки. Clash Verge Rev без чужой подписки — пустая оболочка.
- **Маршруты человеческими терминами.** «Эти сайты — через Нидерланды, эти программы — напрямую, вот это — через цепочку» настраивается именованными наборами без YAML и без понятий «группа/провайдер/правило». Именованная цепочка переиспользуется и как цель маршрута, и как глобальный путь.
- **Fail-closed по умолчанию.** Утечка мимо VPN исключена политикой движка: пустой маршрут режет трафик, отказ серверов маршрута ведёт в VPN, а не напрямую. В Clash Verge Rev это зависит от того, что заложено в подписке.
- **Лёгкость и портативность как принцип.** Нативный интерфейс без WebView, файлы рядом с exe, минимум следов в системе. Clash Verge Rev тяжелее: пакеты по 50–100 МБ, данные в AppData, системная служба для TUN.
- **Фокус на российских блокировках.** Источники, проверки доступности сервисов и маршрутизация заточены под DPI-контекст РФ; Clash Verge Rev — универсальный инструмент без такой специализации.

## Вердикт

Это клиенты одного ядра и одной лицензии, но разных философий: Clash Verge Rev — зрелая универсальная оболочка для тех, у кого уже есть подписка и кто готов ею управлять, а Лазейка — попытка дать рабочий обход блокировок человеку без подписки, знаний и желания разбираться, ценой доверия к бесплатным публичным серверам и одной платформы. Сегодня Clash Verge Rev объективно сильнее как продукт — по зрелости, платформам и глубине; Лазейка сильнее ровно в той нише, ради которой сделана: «ничего нет, ничего не знаю — но нужно, чтобы работало и не утекло». Конкурируют они лишь частично: пользователю с хорошей платной подпиской Лазейка не нужна, а пользователю без подписки Clash Verge Rev не поможет.
